\section{Introduction}

In parallel and distributed systems, computational loads must often be divided symmetrically among disjoint processes that later require strict coordination. This lab investigates the Message Passing Interface (MPI) by simulating a distributed banking server administering a Joint Fixed Deposit account.

\subsection{Objectives}
\begin{enumerate}
    \item \textbf{Parallel Task Operations:} Simulate two completely independent nodes applying 730 days (2 years) worth of compounded daily interest concurrently.
    \item \textbf{Time \& Random Fluctuation Synchronization:} Emulate volatile market conditions utilizing seed-dependent values. Apply an explicit computational audit delay simulating regulatory cryptographic requirements.
    \item \textbf{Inter-Process Communication (IPC):} Implement explicit message passing (\texttt{comm.send} / \texttt{comm.recv}) ensuring both Node A and Node B receive each other's independently verified maturity balances.
    \item \textbf{Consensus Guarantee:} Assert a robust gathering logic that requires exact numerical consensus between the scattered processes.
\end{enumerate}

\subsection{System Configuration}

\begin{shadedbox}[Environment Parameters]
The experiment scales across \textbf{two independent MPI bounds}:
\begin{itemize}[leftmargin=*]
    \item Node A Base Investment: \$6,555.00 (Phone Iteration: 6555) 
    \item Node B Base Investment: \$5,191.00 (Phone Iteration: 5191) 
    \item Initial Base Growth: 7.0\% Annual + Seeded Variable Disturbance $0.1\% \to 0.9\%$
    \item Cryptographic Delay: 2ms injected computationally.
\end{itemize}
\end{shadedbox}

\section{Source Code}

The underlying implementation relies on \texttt{mpi4py} for parallel context distribution mapping Node A (Rank 0) and Node B (Rank 1). Notice carefully the \texttt{comm.send}, \texttt{comm.recv} for messaging, and \texttt{comm.gather} for verifying absolute numerical agreement.

\begin{codebox}[final\_mpi.py]
\begin{lstlisting}
from mpi4py import MPI
import random
import time

P1          = 6555      # Last 4 digits of Client 1 
P2          = 5191      # Last 4 digits of Client 2 
N_YEARS     = 2         # Timeframe in years
AUDIT_DELAY = 0.002     # Regulatory audit delay per day in seconds
BASE_RATE   = 0.07      # 7.0% annual base interest rate

def compute_maturity(principal, seed, n_years, node_label):
    random.seed(seed)
    amount     = float(principal)
    total_days = n_years * 365
    for day in range(1, total_days + 1):
        bonus      = random.uniform(0.001, 0.009)
        rate_daily = (BASE_RATE + bonus) / 365.0
        amount *= (1 + rate_daily)
        time.sleep(AUDIT_DELAY)
    return amount

def main():
    comm = MPI.COMM_WORLD
    rank = comm.Get_rank()
    size = comm.Get_size()
    if size != 2: return
    
    if rank == 0:
        node_label, principal, seed = "Node A", float(P1), P1
    else:
        node_label, principal, seed = "Node B", float(P2), P2

    # --- Phase 1 & 2: Parallel Computation ---
    maturity = compute_maturity(principal, seed, N_YEARS, node_label)
    comm.Barrier()

    # --- Phase 3: Message Passing (IPC) ---
    if rank == 0:
        comm.send(maturity, dest=1, tag=10)
        partner_maturity = comm.recv(source=1, tag=20)
    else:
        partner_maturity = comm.recv(source=0, tag=10)
        comm.send(maturity, dest=0, tag=20)
    comm.Barrier()

    # --- Phase 4: Consensus Check ---
    total = maturity + partner_maturity
    all_totals = comm.gather(total, root=0)
    
    if rank == 0:
        consensus_ok = abs(all_totals[0] - all_totals[1]) < 1e-9
        if consensus_ok:
            print("CONSENSUS ACHIEVED")

if __name__ == "__main__":
    main()
\end{lstlisting}
\end{codebox}

\section{Conclusion}
This lab successfully demonstrated the application of the Message Passing Interface (MPI) to simulate a distributed financial backend. By strictly segregating the day-by-day compound interest computations into isolated processes (Node A and Node B) and introducing synthetic audit delays, the simulation appropriately modeled real-world distributed processing architectures. The use of MPI IPC protocols (\texttt{comm.send}, \texttt{comm.recv}, and \texttt{comm.gather}) proved effective in mitigating deadlock, securely exchanging sensitive floating-point values, and rigorously affirming consensus across process boundaries. Through this exercise, we observed the efficacy and necessity of robust message passing and consensus mechanisms in scaling fault-tolerant, parallelized applications.
